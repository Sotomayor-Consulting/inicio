## 9. Erros Comuns em Vendas pelo WhatsApp

### O que NÃO Fazer

- **Usar número pessoal:** Misturar pessoal/negócio, problemas de privacidade -- Número dedicado para o negócio
- **Sem perfil de negócio:** Parece pouco profissional -- Perfil completo com catálogo
- **Resposta lenta:** Vendas perdidas -- Auto-respostas + chatbot
- **Sem integração de pagamento:** Clientes não podem pagar no chat -- Stripe Payment Links
- **Enviar spam:** Bloqueado, denunciado -- Só com consentimento, valor primeiro
- **Sem sistema de acompanhamento:** Leads esfriam -- Sequências automatizadas
- **Sem integração CRM:** Dados do cliente perdidos -- Conectar WhatsApp ao CRM
- **Sem catálogo:** Cotações manuais -- Adicionar produtos ao WhatsApp
- **Mensagens genéricas:** Baixo engajamento -- Segmentar e personalizar
- **Sem análise:** Não pode melhorar -- Rastrear todas as métricas
