};

## 5. Passo 4: Integração WhatsApp + Stripe

### Por Que os Pagamentos no WhatsApp Importam

| Benefício | Sem Pagamentos no WhatsApp | Com Pagamentos no WhatsApp |
|----------|---------------------------|--------------------------|
| **Tempo para Pagar** | Horas-dias (fatura, e-mail) | Segundos (link Stripe) |
| **Abandono** | 60-80% (saem do chat para pagar) | 5-10% (pagam no chat) |
| **Conversão** | Baixa (atrito para pagar) | Alta (pagamento instantâneo) |
| **Experiência do Cliente** | Fragmentada (chat → e-mail → pagamento) | Fluida (tudo no chat) |
| **Rastreio** | Manual | Automático (Stripe + CRM) |

### Como Aceitar Pagamentos no WhatsApp

```
MÉTODOS DE PAGAMENTO NO WHATSAPP:

MÉTODO 1: STRIPE PAYMENT LINK (MELHOR)
- Criar um Payment Link no Stripe
- Enviar o link via WhatsApp
- Cliente clica e paga
- Você recebe notificação instantânea
- Melhor para: Todos os negócios

COMO FUNCIONA:
1. Agente: "Pronto para continuar? Aqui está seu link de pagamento:"
2. Cliente: Clica no link
3. Stripe: Abre checkout no navegador
4. Cliente: Insere dados do cartão
5. Stripe: Processa o pagamento
6. Você: Recebe notificação + recibo enviado
7. Cliente: Redirecionado para página de agradecimento

MÉTODO 2: FATURA STRIPE
- Criar e enviar fatura
- Fatura inclui link de pagamento
- Cliente paga pela fatura
- Melhor para: B2B, vendas de alto valor

MÉTODO 3: SESSÃO DE CHECKOUT STRIPE
- Gerar sessão de checkout
- Compartilhar link de uso único
- Experiência de checkout com sua marca
- Melhor para: E-commerce, assinaturas
```

```javascript
// Fluxo completo de pagamento WhatsApp + Stripe

const fluxoPagamentoWhatsApp = async (customer, cart) => {
  // 1. Calcular total
  const total = cart.items.reduce((sum, item) => sum + item.price * item.qty, 0);
  
  // 2. Criar Stripe Payment Link
  const paymentLink = await stripe.paymentLinks.create({
    line_items: cart.items.map(item => ({
      price: item.priceId,
      quantity: item.qty,
    })),
    metadata: {
      customerPhone: customer.phone,
      customerName: customer.name,
      source: 'whatsapp',
    },
    after_completion: {
      type: 'redirect',
      redirect: { url: 'https://empresa.com/obrigado' },
    },
  });
  
  // 3. Enviar mensagem WhatsApp com link de pagamento
  await whatsapp.sendTemplate({
    to: customer.phone,
    template: 'solicitacao_pagamento',
    language: 'pt_BR',
    components: [
      {
        type: 'body',
        parameters: [
          { type: 'text', text: customer.name },
          { type: 'currency', currency: { amount: total * 100, code: 'BRL' } },
          { type: 'text', text: paymentLink.url },
        ],
      },
    ],
  });
  
  // 4. Acompanhar se não pagar em 1 hora
  setTimeout(async () => {
    const paid = await checkPaymentStatus(paymentLink.id);
    if (!paid) {
      await whatsapp.sendMessage({
        to: customer.phone,
        text: 'Olá {{name}}! Seu link de pagamento ainda está disponível. Precisa de ajuda?',
      });
    }
  }, 3600000);
  
  return { paymentLink: paymentLink.url, total };
};
```

// Analítica de vendas no WhatsApp com Stripe

const getAnaliticaWhatsApp = async (startDate, endDate) => {
  // Cobranças do Stripe com fonte WhatsApp
  const charges = await stripe.charges.list({
    created: { gte: startDate, lte: endDate },
  });
  
  const whatsAppCharges = charges.data.filter(
    c => c.metadata.source === 'whatsapp'
  );
  
  const revenue = whatsAppCharges.reduce((sum, c) => sum + c.amount, 0);
  const orders = whatsAppCharges.length;
  const avgOrderValue = orders > 0 ? revenue / orders : 0;
  
  // Métricas do WhatsApp API
  const messages = await whatsapp.getAnalytics(startDate, endDate);
  
  return {
    period: { start: startDate, end: endDate },
    conversations: messages.conversations,
    messages: messages.total,
    revenue: revenue / 100,
    orders,
    avgOrderValue: avgOrderValue / 100,
    conversionRate: orders > 0 
      ? (orders / messages.conversations) * 100 
      : 0,
    revenuePerConversation: messages.conversations > 0
      ? (revenue / 100) / messages.conversations
      : 0,
  };
};
