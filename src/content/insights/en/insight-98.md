## 2. Step 1: Form a U.S. Business Entity

## 6. Step 5: Manage Taxes and Compliance

### U.S. Tax Obligations for Foreign-Owned LLCs

| Tax Form | Filing Frequency | Who Must File |
|----------|-----------------|---------------|
| **Form 5472** | Annual | Foreign-owned single-member LLCs |
| **Form 1120** | Annual | Foreign-owned multi-member LLCs (electing corp status) |
| **Form 1065** | Annual | Multi-member LLCs (partnership) |
| **IRS W-8BEN-E** | Every 3 years | Foreign entities claiming treaty benefits |
| **FBAR** | Annual | If foreign accounts exceed $10,000 |
| **State Reports** | Annual/Biennial | Varies by state (Wyoming: $60, Delaware: $300) |

## 8. Common Mistakes When Accessing the U.S. Financial System

### What NOT to Do

| Mistake | Consequence | Solution |
|---------|-------------|---------|
| **Using personal accounts for business** | Frozen accounts, tax issues | Open a dedicated business account |
| **Ignoring IRS filing requirements** | $25,000+ penalties for Form 5472 | File annually with a tax professional |
| **Choosing wrong state for LLC** | High annual fees, complicated taxes | Wyoming or New Mexico for most foreigners |
| **Not reporting foreign accounts (FBAR)** | $10,000+ penalties | File FBAR if foreign accounts > $10,000 |
| **Using unregulated crypto exchanges** | Frozen funds, compliance issues | Use regulated platforms (Coinbase, Kraken) |
| **Mixing personal and business Stripe accounts** | Account restrictions | Dedicate one Stripe account per LLC |
| **Skipping registered agent service** | Loss of good standing | Use a professional registered agent |
| **Not maintaining a U.S. address** | Bank account closures | Use a virtual mailbox or registered agent address |

## 9. Complete Checklist to Access the U.S. Financial System

### PHASE 1: BUSINESS FORMATION (Week 1-2)

- [ ] Choose LLC state (Wyoming recommended for most)
- [ ] Register LLC with the state
- [ ] Apply for EIN from IRS (online, immediate)
- [ ] Create Operating Agreement
- [ ] Hire a registered agent
- [ ] Get a virtual U.S. address (if needed)

### PHASE 2: BANKING (Week 2-3)

- [ ] Open Mercury or Relay business account
- [ ] Verify identity with passport and EIN letter
- [ ] Fund the account (wire or Wise transfer)
- [ ] Order debit card (virtual first, physical later)
- [ ] Set up multi-factor authentication with U.S. phone number

### PHASE 3: PAYMENT PROCESSING (Week 3-4)

- [ ] Create Stripe account with U.S. LLC details
- [ ] Connect your U.S. bank account for payouts
- [ ] Set up PayPal Business (optional but recommended)
- [ ] Configure payment methods (ACH, cards, Link)
- [ ] Test a transaction end-to-end

### PHASE 4: COMPLIANCE (Ongoing)

- [ ] Schedule annual IRS filing (Form 5472)
- [ ] Register for state annual report reminders
- [ ] Set up FBAR filing if applicable
- [ ] Configure Stripe Tax for sales tax (if selling in US)
- [ ] Keep operating agreement and records updated

### PHASE 5: GROWTH (Month 3+)

- [ ] Apply for DUNS number
- [ ] Open Net-30 trade accounts (Uline, Grainger)
- [ ] Apply for business credit card
- [ ] Explore investment platforms (Interactive Brokers)
- [ ] Set up multi-currency accounts (Wise)
